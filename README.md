# xrwvm-fullstack_developer_capstone

## Project Name: fullstack_developer_capstone

A full-stack web application for car dealership reviews, built with Django (backend), React (frontend), and Node.js microservices. This capstone project demonstrates end-to-end development including REST APIs, sentiment analysis, CI/CD pipelines, and cloud deployment.

### Repository: xrwvm-fullstack_developer_capstone
### Technologies: Django, React, Node.js, MongoDB, Docker, GitHub Actions
